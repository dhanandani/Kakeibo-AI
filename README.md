# Kakeibo AI

Kakeibo AI is a personal finance management web application developed using Python, Flask, SQLite, HTML, CSS, and Matplotlib.

The application helps users track daily expenses, monitor budgets, visualize spending patterns, and receive AI-powered spending advice.

## Features

* User Login & Logout System
* Add and Delete Expenses
* Expense Search Function
* Budget Tracking
* Budget Warning Notifications
* Expense Category Dashboard
* Expense Statistics
* Expense Date Tracking
* CSV Export
* Pie Chart Visualization
* Daily Expense Trend Chart
* AI Spending Advice
* Dark Mode
* English & Japanese Pages
* PDF Report Export

## Technologies Used

* Python
* Flask
* SQLite
* HTML
* CSS
* Matplotlib
* ReportLab
* JavaScript

## AI Features

The application analyzes spending behavior and provides smart financial advice based on:

* Food expenses
* Shopping expenses
* Bills and fixed costs
* Remaining budget

## Project Purpose

This project was created to improve Python web development skills and learn:

* Backend Development with Flask
* Database Management with SQLite
* Data Visualization using Matplotlib
* User Interface Design with HTML/CSS
* Personal Finance Management Concepts
